# Aisia - A Film Social Network App

A social network desktop application built in **Java (Swing)** that combines elements of **Twitter** with **Letterboxd/IMDb**.  

## Features  
- 📌 **Feed system**: Post updates and view posts from users you follow.  
- 🎥 **Favorite movies**: Add and manage your personal list of favorite films.  
- 🌐 **Box office integration**: Fetch and display real-time box office data using **HTTP requests**.  
- 👥 **User interaction**: Follow other users and see their activity.
